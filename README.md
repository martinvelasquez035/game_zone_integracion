# game_zone_integracion

# GameZone App

GameZone es una aplicación desarrollada en Flutter que permite consultar información sobre videojuegos de una manera visual e interactiva. La aplicación incluye un sistema de gestión de juegos donde el usuario puede agregar, editar, eliminar y marcar videojuegos favoritos.

El proyecto fue desarrollado como parte del reto de integración de Flutter utilizando un CRUD simulado con arquitectura organizada, validaciones y servicios en memoria.

# Cómo usar la aplicación

1. Inicia sesión con el usuario de prueba o crea una cuenta nueva desde la pantalla de registro.

2. Una vez dentro de la aplicación podrás visualizar la lista de videojuegos disponibles junto con información básica de cada uno.

3. Los usuarios pueden agregar nuevos videojuegos personalizados o ampliar y modificar la información de los videojuegos ya existentes.

4. Presiona el botón "+" para agregar un nuevo videojuego ingresando nombre, descripción e imagen.

5. Usa el botón ✏️ para editar la información de un juego existente.

6. Usa el botón 🗑️ para eliminar videojuegos. La aplicación solicitará confirmación antes de eliminarlos.

7. Presiona el botón ❤️ para agregar o quitar videojuegos favoritos.

8. Para acceder al perfil de usuario debes hacer clic en el icono de perfil ubicado en la parte superior derecha de la aplicación.

9. En el perfil podrás visualizar la información de la cuenta y los videojuegos marcados como favoritos.

10. Presiona “Ver más” para acceder a la información detallada de cada videojuego.
